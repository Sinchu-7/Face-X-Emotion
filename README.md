# Face-X-Emotion 🎭
### Real-Time Facial Emotion Recognition Using Deep Learning

Face-X-Emotion is an AI-powered facial emotion recognition web application that detects and analyzes human facial expressions using computer vision and deep learning. The application supports webcam-based emotion detection and image-based analysis, providing emotion labels and confidence scores through an interactive web interface.

---

## 📌 Project Overview

Human facial expressions play an important role in understanding emotions and communication. Face-X-Emotion aims to identify human emotions automatically by analyzing facial expressions using artificial intelligence.

The application uses Flask for backend development, DeepFace for emotion analysis, and OpenCV for image processing and webcam integration.
